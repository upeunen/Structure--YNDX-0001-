# Архитектура экосистемы: Яндекс.Станция 1 (YNDX-0001) + Пульт ДУ

## 1. Обзор системы и аппаратная платформа

- **Целевое устройство:** Яндекс.Станция 1-го поколения (модель **YNDX-0001**).
- **Процессор / Чипсет:** Allwinner R18 (4 ядра ARM Cortex-A53, 64-bit).
- **Операционная система:** Android 6.0.1 (Marshmallow, API 23), ядро Linux 3.10.65+.
- **Оперативная память (RAM):** 1 ГБ DDR3 (свободно в системе ~110–140 МБ).
- **Сетевое окружение:**
  - IP-адрес Станции в локальной сети: `192.168.100.6`
  - Сетевой ADB-демон (Android Debug Bridge): порт `5555` (доступен без пароля)
  - Стриминговый движок TorrServer Silo: порт `8090` (HTTP REST API + DLNA Streamer)
  - Локальный веб-пульт / сервер: порт `8088`
  - SSH Dropbear: порт `22` (root-доступ)
- **Клиентское устройство:** Смартфон пользователя на базе Android (установлено приложение «Пульт»).
- **Репозиторий проекта:** `https://github.com/upeunen/Structure--YNDX-0001-` (ветка `main`).

## 3. Компоненты на Яндекс.Станции

### 3.1. Стриминговый движок TorrServer Silo
- **Бинарник:** `/data/local/bin/torrserver` (TorrServer Silo.2, engine v1.2.33, arm64).
- **Конфигурационный файл:** `/data/torrserver/config.yaml`
  - `host: 0.0.0.0`
  - `port: 8090`
  - `cache_size_mb: 35` (критично для стабильности: ограничение 35 МБ кэша в ОЗУ предотвращает OOM-вылеты Linux на 1 ГБ памяти Станции)
  - `peers_limit: 30` (защита от перегрузки сетевого стека)
  - `ffmpeg.enabled: false` (отключение программного перекодирования на стороне сервера)
- **Супервайзер автозапуска:** `/data/local/bin/torrserver_service.sh`
  - Проверяет процесс каждые 3 секунды. При падении автоматически перезапускает с файлом конфигурации.
- **Главный автозапуск Станции:** `/data/local/bin/userinit.sh`
  - Поднимает Dropbear SSH, веб-сервер 8088 и супервайзер `torrserver_service.sh &`.

### 3.2. Воспроизведение медиа
- **Основной видеоплеер (VLC):** `org.videolan.vlc` (VLC for Android 3.6.5 `arm64-v8a`, установлен на Станцию).
  - Поддерживает все звуковые дорожки (AC3, DTS, E-AC3, AAC, MP3) и переключение дорожек/субтитров с пульта.
  - Поток запрашивается из локального TorrServer: `http://127.0.0.1:8090/api/stream/<hash>/<fileId>`.
- **Резервный аппаратный плеер:** `com.softwinner.fireplayer/.ui.VideoPlayerActivity` (используется, если VLC не установлен).
- **YouTube плеер:** `org.smarttube.stable`
  - При запуске YouTube принудительно останавливаются `fireplayer` и `org.videolan.vlc`, чтобы освободить аппаратный видеодекодер.
  - Запуск видео: `am start -a android.intent.action.VIEW -d "<url>" -p org.smarttube.stable`
  - Поиск: `am start -a android.intent.action.SEARCH -q "<query>" -p org.smarttube.stable`
- **Родной экран Алисы:** `ru.yandex.quasar.app`
  - Главный экран часов: `am start -a android.intent.action.MAIN -c android.intent.category.HOME`
  - Остановка плееров: принудительный `force-stop` для `com.softwinner.fireplayer`, `org.videolan.vlc`, `org.smarttube.stable`, `top.rootu.lampa` и передача `keyevent 86` (STOP) + `keyevent 3` (HOME).

## 4. Архитектура Android-приложения «Пульт»

### 4.1. Стек технологий
- **Язык:** Kotlin 1.9+.
- **UI:** Jetpack Compose (Material Design 3).
- **Архитектура:** MVVM (Model-View-ViewModel) + Kotlin StateFlow / Coroutines.
- **Сетевое взаимодействие:**
  - `AdbClient.kt`: собственная реализация протокола ADB поверх TCP-сокетов (порт 5555) без использования сторонних внешних утилит. Поддерживает команды `shell:...`, таймаут 6 сек, автоматическую очистку потоков.
  - `TorrServerClient.kt`: взаимодействие с REST API TorrServer Silo (добавление магнитов/торрентов, выбор лучшего видеофайла, предзагрузка буфера `preload`, пробуждение `wake`).
  - `Storage Access Framework (SAF)`: выбор файлов `.torrent` любого размера и формата со смартфона через `OpenDocument`.

### 4.2. Навигация и экраны
- **Модальный экран («Пульт»):**
  - Открывается поверх любого текущего экрана по яркой кнопке **Пульт** в центре верхней шапки.
  - Виртуальный D-pad (Вверх, Вниз, Влево, Вправо, ОК).
  - Управление воспроизведением (Play/Pause, плавная перемотка `−1 мин / −10 сек / +10 сек / +1 мин`, переключение серий Prev/Next, Громкость, Меню, Назад).
  - Быстрые кнопки управления: **🔊 Дорожка** (переключение аудиодорожки на ТВ), **💬 Субтитры** (включение/переключение субтитров), **⭐ Закладка** (сохранение текущего фильма или ролика в закладки).
  - Вкладка **Ввод текста** для удаленного набора текста на ТВ.
- **Стартовый экран («Кинозал»):**
  - Горизонтальные категории: **«🕒 История»**, **«⭐ Закладки»**, **«🎬 Сборки»** (RuTracker), **«📌 Смотреть позже»**.
  - На каждой карточке доступна иконка корзинки для удаления пункта из любого списка с диалогом подтверждения.
  - Умная буферизация до 1.5 МБ с прогрессом на экране, диалог выбора серии для многофайловых раздач, запоминание позиции просмотра и автопереключение на следующую серию.
  - Экран **«Сборки / Браузер RuTracker»**:
    - Автоматически запоминает последнюю открытую страницу при просмотре.
    - Кнопка **«Домой»** (иконка домика) возвращает на стартовый каталог фильмов.
    - Долгое нажатие (удержание) на кнопку «▶ Запустить на ТВ» сохраняет фильм в список **«📌 Смотреть позже»** с виброоткликом.
- **Экран («YouTube»):**
  - Быстрые кнопки управления SmartTube (**Главная**, **Меню**, **Поиск**) и кнопка **⭐ Закладка** для сохранения текущего ролика в историю приложения.
  - Карточки истории с возможностью удаления по иконке корзинки с подтверждением.
- **Нижняя панель (фиксирована на всех экранах):**
  - **Кинозал** — стартовый экран с историей торрентов и кнопкой «Подборки».
  - **Алиса** — экстренная кнопка мгновенной остановки всего видео и возврата на часы Алисы.
  - **YouTube** — управление SmartTube и история видео.

### 4.3. Решение ключевых проблем
1. **Сброс соединения при загрузке `.torrent` файлов (`ConnectionResetError`):**
   - Было: разделитель `multipart/form-data` содержал знаки `=`, из-за чего HTTP-парсер TorrServer Silo сбрасывал соединение.
   - Стало: используется чистый буквенно-цифровой `boundary` без `=`, явный `Content-Length` и ASCII-имя файла в заголовке `Content-Disposition`.
2. **Ожидание раздачи и буфера вместо слепого таймера:**
   - Было: плеер запускался через фиксированные 3.5 секунды, даже если раздача не нашла пиров.
   - Стало: приложение ждёт получения реального списка файлов (`waitForVideoFiles`), предлагает выбор серии (если файлов > 1), запускает `preload` и ждёт наполнения буфера минимум до 1.5 МБ (`waitForBuffer`).
3. **Отсутствие звука в `.mkv` (AC3/DTS) и освобождение видеодекодера:**
   - На Станцию установлен **VLC 3.6.5**, поддерживающий AC3/DTS и переключение аудиодорожек (`keyevent 30`) и субтитров (`keyevent 50`).
   - Перед запуском YouTube или видеоплеера принудительно останавливаются конкурирующие плееры, чтобы освободить аппаратный видеодекодер Allwinner.
4. **Зависания и ошибки при нажатии кнопки «Алиса»:**
   - Вызов стандартного намерения `android.intent.category.HOME` и `input keyevent 3` чисто возвращает интерфейс часов `ru.yandex.quasar.app/.MainActivity`.

## 5. Порты, команды и сценарии использования

| Назначение | Команда / Запрос | Порт / Протокол |
|---|---|---|
| Проверка связи ADB | Сокетное рукопожатие `A_CNXN` | 5555 (TCP) |
| Вызов часов Алисы | `am force-stop com.softwinner.fireplayer; am force-stop org.smarttube.stable; input keyevent 86; input keyevent 3; am start -a android.intent.action.MAIN -c android.intent.category.HOME` | 5555 (ADB) |
| Запуск фильма из TorrServer | `am force-stop org.smarttube.stable; am start -n com.softwinner.fireplayer/.ui.VideoPlayerActivity -a android.intent.action.VIEW -d "<streamUrl>" -t "video/*"` | 5555 (ADB) |
| Добавление Magnet | `POST /api/torrents` (JSON `{"link":"magnet:...", "title":"..."}`) | 8090 (HTTP) |
| Загрузка файла `.torrent` | `POST /api/torrents` (multipart/form-data) | 8090 (HTTP) |
| Пробуждение торрента | `POST /api/torrents/<hash>/wake` | 8090 (HTTP) |
| Буферизация файла | `POST /api/torrents/<hash>/files/<id>/preload` | 8090 (HTTP) |
| Видеопоток для плеера | `http://127.0.0.1:8090/api/stream/<hash>/<id>` | 8090 (HTTP) |
