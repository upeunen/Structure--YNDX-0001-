# Пульт управления для Яндекс.Станции 1 (YNDX-0001)

Легковесное и быстрое Android-приложение для управления мультимедиа-функциями Яндекс.Станции 1 поколения (Allwinner R18, Android 6.0.1) по локальной сети Wi-Fi через прямой протокол ADB (порт 5555).

## Возможности

1. **Главный экран (Сенсорный пульт):**
   - **D-pad навигация:** Вверх (19), Вниз (20), Влево (21), Вправо (22) и центральная кнопка «ОК» (66).
   - **Быстрые действия:** «Назад» (4), «Пауза / Плей» (85), Громкость «−» (25) и «+» (24).
   - **Мгновенный запуск режимов в 1 клик:**
     - **YouTube** → Запуск SmartTube (`org.smarttube.stable`)
     - **🎬 Кино** → Запуск медиацентра Kodi (`org.xbmc.kodi`)
     - **🏠 Алиса** → Остановка сторонних плееров и возврат часов/домашнего экрана Яндекс.Станции (`ru.yandex.quasar.app`)

2. **Запуск YouTube роликов:**
   - Поле для ввода адреса видео.
   - Быстрая вставка ссылки из буфера обмена.
   - Кнопка «Смотреть на ТВ» — видео мгновенно запускается на телевизоре без рекламы.

3. **Интеграция с системным меню «Поделиться» (Send to TV):**
   - Нажмите «Поделиться» под любым роликом в официальном приложении YouTube на телефоне и выберите «Пульт Станции».
   - Видео сразу отправится на воспроизведение на Станции со всплывающим уведомлением.

4. **Интерфейс и эргономика:**
   - Тема OLED Black (глубокий черный фон для экономии батареи и комфорта глаз).
   - Мягкий тактильный виброотклик при нажатии на кнопки.
   - Экран настроек с возможностью изменить IP (по умолчанию `192.168.100.6`) и порт (`5555`), а также проверить доступность Станции.
