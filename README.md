# 📱 Пульт для Яндекс.Станции 1 (YNDX-0001)

Мобильное Android-приложение на **Kotlin + Jetpack Compose** для полного управления мультимедиа на **Яндекс.Станции 1-го поколения** (`Allwinner R18`, `Android 6.0.1`, `1 ГБ RAM`) по домашнему Wi-Fi — без рекламы, тормозов и лишних пультов.

Подробная техническая схема экосистемы описана в [ARCHITECTURE.md](ARCHITECTURE.md).

---

## ✨ Основные возможности

### 🎬 Кинозал (TorrServer Silo + VLC)
- **Автозапуск движка на Станции:** при открытии Кинозала приложение автоматически проверяет и запускает `TorrServer Silo` (порт `8090`) на Станции через ADB.
- **Умная буферизация (без слепых таймеров):** ожидание реального списка файлов раздачи (`file_stats`), предзагрузка (`preload`) и контроль наполнения буфера до **1.5 МБ** перед стартом плеера.
- **Выбор серий и автопереключение:** для сериалов открывается список серий с размерами, запоминается последняя серия и позиция просмотра, а по окончании текущей серии автоматически запускается следующая.
- **Добавление вручную:** выбор локальных `.torrent` файлов со смартфона (через SAF) и вставка `magnet:`-ссылок (с автоматическим добавлением живых трекеров).
- **Воспроизведение через VLC:** фильмы запускаются в установленном на Станцию **VLC 3.6.5 (`arm64`)** с поддержкой любых звуковых дорожек (AC3, DTS, E-AC3, AAC, MP3) и субтитров.
- **История и закладки:** реальная история запущенных фильмов и сериалов (от новых к старым) + встроенная панель **Логи** с кнопкой копирования.

### 🎞 Подборки (встроенный RuTracker)
- Отдельный экран с каталогом `https://rutracker.net/forum/index.php?c=2` прямо внутри приложения (с сохранением сессии/cookies и обложками из листинга).
- Кнопки скачивания `.torrent` и `magnet:` автоматически заменяются на **«▶ Запустить на ТВ»** — фильм сразу уходит на Станцию и запускается на телевизоре.

### 🎮 Модальный Пульт (сверху по центру)
- Доступен с любого экрана по яркой кнопке **Пульт** в центре верхней шапки (открывается поверх всех окон).
- **Крестовина (D-pad)** + центральная кнопка **ОК**.
- **Управление воспроизведением:** Play/Pause, плавная перемотка (`−1 мин`, `−10 сек`, `+10 сек`, `+1 мин`), переключение серий (`Prev`/`Next`), громкость, меню плеера, а также быстрые кнопки **🔊 Аудиодорожка** и **💬 Субтитры** для VLC.
- **Ввод текста:** удалённый набор текста с клавиатуры телефона прямо на экран телевизора.

### ▶ YouTube (SmartTube)
- Быстрые кнопки управления SmartTube на ТВ: **Главная**, **Меню**, **Поиск** и **⭐ Закладка** (сохранение текущего видео в историю приложения).
- Отправка ссылок и поисковых запросов на ТВ, автоматическое подтягивание реальных названий видео, история 20 последних роликов.
- Перехват системного меню **«Поделиться»** из приложения YouTube на смартфоне.

### 🏠 Алиса (1 касание)
- Кнопка **Алиса** в нижней панели мгновенно останавливает все плееры (VLC, FirePlayer, SmartTube) и возвращает на ТВ родной экран часов Алисы (`ru.yandex.quasar.app`).

## 🧭 Навигация в приложении

- **Верхняя шапка (центр):** кнопка **Пульт** (модальное окно поверх всех экранов).
- **Нижняя панель:** `Кинозал` • `Алиса` • `YouTube`.

## ⚙️ Стек и компоненты на Станции

| Компонент | Назначение | Порт / Пакет |
|---|---|---|
| **AdbClient** | Собственный ADB-клиент на TCP-сокетах | `5555` |
| **TorrServer Silo** | Стриминг торрентов (кэш 35 МБ, 30 пиров) | `8090` |
| **VLC for Android** | Основной видеоплеер (AC3/DTS/субтитры) | `org.videolan.vlc` |
| **FirePlayer** | Резервный аппаратный плеер Allwinner | `com.softwinner.fireplayer` |
| **SmartTube** | YouTube-клиент без рекламы | `org.smarttube.stable` |
| **Яндекс.Станция** | Родной экран часов и Алисы | `ru.yandex.quasar.app` |

## 📲 Требования и установка

> **Важно:** перед использованием приложения на самой **Яндекс.Станции 1 (YNDX-0001)** предварительно должен быть получен **root-доступ**, включён сетевой **ADB** (порт `5555`), установлен **TorrServer Silo** (порт `8090`), а также плееры **VLC** и **SmartTube**.

1. Скачайте готовый установочный файл из корня репозитория: [`app-release.apk`](app-release.apk).
2. Установите APK на Android-смартфон, подключённый к той же Wi-Fi сети, что и Яндекс.Станция.
3. При необходимости укажите IP Станции в настройках (по умолчанию `192.168.100.6`, порт `5555`).
